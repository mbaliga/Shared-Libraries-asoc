Stays on this device until you send it. No network permission in the module manifest — sharing is a manual chooser, never an upload. Secrets are replaced with typed placeholders, and the stream profile additionally asserts no raw signal values reached the file.

Profile-aware, not frame-awareThe panel reads the active profile's primary series. On audio the headline is a callback against the buffer period; on service it is request latency against an SLA. A panel that says "fps" over an instrument app is worse than no panel.
Budget line is derivedNever a hardcoded 16.7 ms. It comes from the actual refresh rate, the negotiated buffer, the capture cadence, or a stated SLA — and the sparkline scales to it, so the same widget reads correctly at 8 ms and at 2 000 ms.
Interval series get a tolerance bandCamera cadence and sensor spacing jitter around nominal by construction, so ~half of a healthy stream sits above it. Those series mark overruns only past a multiple of nominal — otherwise the panel would scream permanently and be ignored.
Refusal is a featureFor ime and wallpaper the overlay would cover or steal input from the surface under measurement. It refuses rather than quietly corrupting the run, and points at the ADB trigger.
Invariants over percentilesThe chips carry structural claims, not thresholds — accelerated delegate in use, nothing drawing while hidden, no egress while BYO-AI is off. Each is glyph + word + border, never colour alone.
